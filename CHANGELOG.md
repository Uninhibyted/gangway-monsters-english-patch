# Changelog

## [v0.3.1](../../releases)

* The name entry grid shows full-width letters spaced like the Japanese, and the cursor moves
  between them as in the original.

## [v0.3](../../releases/tag/v0.3)

* Rewrote the English by hand across the whole game: field events and conversations, menus,
  items and monsters, the casino and its mini-games, battle and VS mode text, the title screen,
  the monster book, and the opening and ending.
* Translated the menus and labels drawn as images: the Garage menu, world map, stadium menus,
  shop, status screen, Option and Key Config screens, Pockle Card hands, Pockle Race, Pockle
  Stone and the credits.
* Field conversations are no longer limited to the length of the Japanese, and their text wraps
  between words instead of mid-word.
* Menus, the opening dialogue and other text can be longer than the Japanese where needed.
* The VS screen shows English names of up to 12 characters, digits included.
* Fixed text running on past a line break after an odd number of letters, including with
  odd-length player names.
* The memory card save is titled GANGWAY MONSTERS.
* The patch is now an xdelta file that can be applied in the browser with Rom Patcher JS.
